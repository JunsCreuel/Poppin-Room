# CSL Gacha v2 — 왁뿌볼 · 키캡 피젯 랩

박준성님 `CSL v2 재기획안`(2026.09.14)에 적힌 프롬프트 순서 그대로 구현한 첫 시안입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

## 구현된 것 (문서 4번 "반드시" 항목 기준)

- 왁뿌볼 8종 (common 3 · rare 3 · limited 2), 키캡 8종 (common 3 · rare 3 · limited 2)
  — 실제 아트는 아직 1종(핑크 유리볼 / ESC 키캡)뿐이라, 기존 CRACK·CLICK LAB 이미지를 그대로 가져와 CSS `filter`(hue-rotate 등)로 8가지 색 변형을 만드는 방식으로 채웠습니다. 실제로 새로 그린 아트가 생기면 `src/data/toys.json`의 `image` 필드만 바꾸면 됩니다.
- 왁뿌볼 룸 — 클릭 연타로 금 가다가 깨짐, 깨지면 파편 애니메이션 + 사운드 + 게이지, 새 볼로 리셋
- 키캡 룸 — 8키 미니 키보드, 마우스 클릭 + 실제 키보드(숫자 1~8) 둘 다 반응, 타건 사운드 + 게이지
- 뽑기 — 게이지 100 차면 1회, 등급 확률 Common 70% / Rare 25% / Limited 5%, 캡슐 흔들림 → 결과 카드 연출(limited는 화면 흔들림), 중복 뽑기 시 게이지 30% 환급
- 컬렉션 도감 — 미획득은 실루엣(`???`), 클릭하면 장착
- localStorage 저장 — 새로고침해도 게이지·보유·장착 상태 유지
- 반응형 — 모바일 폭에서도 가로 스크롤 없이 동작 확인

## 에셋 출처

- **왁뿌볼 이미지**: `crack-app/public/images/wax_ball.png` 그대로 사용
- **키캡 이미지**: `click-app/public/images/esc_key.png` 그대로 사용
- **키캡 타건 사운드**: `click-app/public/sounds/keyboard.mp3` 그대로 사용 (실제 녹음 파일)
- **왁뿌볼 크런치/파괴 사운드**: `crack-app/src/crunch.js`의 Web Audio 합성 로직을 그대로 포팅 (CRACK LAB도 아직 실제 녹음 파일 없이 이 방식 사용 중이라 동일하게 맞춤)
- **뽑기 성공 사운드만** 아직 아무 에셋도 없어서 임시 합성음(`src/utils/sound.js`의 `playGachaSuccess`)으로 대체 — 나중에 실제 사운드 생기면 이 함수만 `<audio>` 재생으로 교체
- 음량 설정은 메인 사이트와 같은 `csl-volume` localStorage 키를 공유하도록 `volume.js`도 그대로 포팅

## 아직 없는 것

- 왁뿌볼·키캡 각각 8종에 대응하는 **실제 개별 아트** (지금은 색 필터로 대체 — 홀로그램/골드 한정판 2종은 반짝이는 애니메이션 필터로 특별하게 보이게 처리)
- 캡슐머신 그래픽 (지금은 핑크 원형으로 단순화)
- 데일리 보너스, 한정판 기간제, 공유 카드(문서 "여유 되면" 항목)
- 비주얼 톤 A(기밀문서 케이스파일)를 기본으로 잡았고, 뽑기 화면에 B(캡슐토이) 느낌을 살짝 섞음 — 문서 추천안 그대로.
