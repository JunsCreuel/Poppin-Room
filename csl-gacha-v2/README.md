# CSL Gacha v2 — 왁뿌볼 · 키캡 피젯 랩

박준성님 `CSL v2 재기획안`(2026.09.14)에 적힌 프롬프트 순서를 뼈대로, 이후 피드백(흰 배경, 단일 키캡, 무료/유료/프리미엄 코인 경제, 히든카드)까지 반영한 버전입니다.

## 왁뿌볼 깨지는 손맛 — 크런치 → 찌그러짐

CRACK LAB(`crack-app`, 참고용으로 팀에서 공유한 wakbuball-game.pages.dev)의 "다 깨진 뒤에도 내용물이 찌그러지며 계속 만질 수 있는" 인터랙션을 우리 방식대로 다시 구현했습니다. 디자인을 그대로 베낀 게 아니라 **기능만 참고**하고, 색 처리는 우리 시스템에 맞게 다르게 했습니다.

- 누를 때마다 최소 260ms 간격을 두고서만 타격이 등록됨(`HIT_COOLDOWN_MS`) — 그 안에 더 눌러도 무시돼서 "탁탁탁탁" 연타가 아니라 "탁···탁···탁" 한 번씩 묵직하게 박히는 느낌을 줌
- 다 깨지기 전부터 진행도에 비례해서 금 간 틈으로 흰 왁스가 조금씩 비침(`CrackOverlay.jsx`의 `wakpu-wax-glow`/`wakpu-wax-drop`) — 예를 들어 15번 쳐야 깨지는 왁뿌볼이면 초반 몇 번만 쳐도 벌써 살짝 하얗게 비치기 시작해서, 다 깨질 때 갑자기 왁스가 나타나는 게 아니라 자연스럽게 이어짐
- 칠 때마다 진행도에 비례해서 점점 더 세게 짓눌렸다 튕기는 반응 (`WakpuStage.jsx`, `--hit-squash` CSS 변수)
- 다 깨지면 끝나는 게 아니라, 겉껍질이 파편으로 튄 뒤 안에 있던 흰색/크림색 왁스만 찌그러진 모습으로 잠깐 남아서 계속 조몰락거릴 수 있음 — 이때도 계속 코인이 나옴. 겉껍질은 디자인마다 다른 `accent` 색 파편으로, 안의 왁스는 디자인과 무관하게 항상 흰색으로 통일
- 왁뿌볼 룸·히든 왁뿌볼 룸이 이 로직을 공유(`WakpuStage.jsx`)
- 키캡 룸·히든 키캡 룸은 이 쿨다운을 공유하지 않음(별도의 `Keycap.jsx`/`HiddenKeycap.jsx` 클릭 핸들러) — 실제로 만졌을 때 왁뿌볼과 키캡은 속도감이 다르기 때문에, 키캡은 누르는 대로 "탁탁탁탁" 그대로 반응함

## 등급 구조 — 무료 / 유료 / 프리미엄

디자인 등급(common/rare/limited 배지)과 별개로, **획득 방식**을 결정하는 `tier` 필드가 있습니다.

| tier | 배지 | 획득 방법 |
|---|---|---|
| `free` | COMMON | 처음부터 자동 보유 (왁뿌볼·키캡 각 3종) |
| `paid` | RARE | 뽑기 전용 — 코인 10개 소비, 유료 등급 중 랜덤 1개 (각 3종) |
| `premium` | LIMITED | 스토어에서 실제 결제로 구매 (각 2종, ₩2,900~3,900) |

## 코인 경제

- 왁뿌볼을 칠 때마다, 키캡을 누를 때마다 랜덤 보상 굴림: **35% 1코인 · 5% 5코인**. 일반 룸에서는 코인만 나오고 히든카드는 안 나옴(히든카드는 히든 룸 전용, 아래 참고)
- 뽑기 1회 = 코인 10개. 이미 보유 중인 디자인이 나오면 코인 30% 환급
- 광고 보고 5코인 받기 — 실제 광고 SDK가 없어서 지금은 "광고 재생 중..." 흉내만 내고 5코인을 바로 지급하는 mock (`Gacha.jsx`의 `handleWatchAd`, `useGame.jsx`의 `claimAdCoins`)

## 히든카드 & 히든 룸

- 일반 왁뿌볼/키캡 룸과는 완전히 분리된 전용 룸(**히든 왁뿌볼**, **히든 키캡**)이 있음 — 여기서는 코인이 전혀 안 나오고, 누를 때마다 **0.6% 확률로 히든카드만** 노려볼 수 있음. 두 룸 모두 룸 고유의(장착한 디자인과 무관한) 어둠 속 보석 아트로 고정돼 있음
- 하루 시도 횟수 제한: 기본 **40번**, 다 쓰면 **광고 1편(30초) 시청당 20번씩 최대 60번**까지 늘릴 수 있음 (`HiddenGauge.jsx`)
- 60번(또는 광고 없이 40번)을 전부 쓰면, **그 주기가 시작된 시점으로부터 24시간**이 지나야 40번으로 다시 풀림 — 달력 날짜가 아니라 실제 24시간 롤링 윈도우 (`useGame.jsx`의 `pressHidden`/`isHiddenMaxed`, `HIDDEN_CYCLE_MS`)
- 히든카드를 획득하면 화면 전체 축하 모달 표시 → 「내 계정」 탭에 코드·획득일과 함께 계속 보관됨
- 실물 상품 수령에는 실제 계정 시스템이 필요하다는 안내만 표시(아직 미구현)

## 로그인 (mock)

- 헤더 우측 "로그인" → 카카오/Google 버튼 중 하나 누르면 바로 로그인 처리되는 스텁 (`useGame.jsx`의 `login`/`logout`)
- 실제 OAuth 연동 전까지는 이 mock으로 "로그인 → 내 계정 탭" 흐름만 보여줌
- 로그인 전엔 히든카드·프리미엄 보유 내역이 안 보이고 로그인 유도 화면만 나옴

## 화면 구성 (10개)

1. **LAB** — 코인 잔액, 뽑기 CTA, "일반 룸 / 히든 룸" 탭으로 전환되는 룸 입구 4개(아래 2~5번)
2. **왁뿌볼 룸** *(일반 탭)* — 단일 볼, 연타 → 깨짐 → 코인 굴림, 보유 디자인 즉시 장착(디자인 선택 UI), 오늘 깬 횟수 → 랭킹 링크, 히든 왁뿌볼 룸 CTA
3. **히든 왁뿌볼 룸** *(히든 탭)* — 룸 전용 고정 아트(반짝이는 홀로그램 연출), 코인 없이 0.6% 히든카드만. 하루 40번(광고로 최대 60번), 24시간 롤링 리셋
4. **키캡 룸** *(일반 탭)* — 단일 키(8키 보드 아님), 클릭할 때마다 눌림 상태 토글(꾹 누르기 연타 없음) + 실제 ESC 키 → 코인 굴림, 보유 디자인 인벤토리에서 즉시 장착, 내 사진을 스티커로 올려 키캡 위에 표시, 히든 키캡 룸 CTA
5. **히든 키캡 룸** *(히든 탭)* — 룸 전용 고정 아트(반짝이는 홀로그램 연출), 코인 없이 0.6% 히든카드만. 하루 40번(광고로 최대 60번), 24시간 롤링 리셋
6. **뽑기** — 코인 소비, 유료 등급만 등장, 결과 화면에서 바로 장착 가능, 실제 캡슐머신 그래픽
7. **도감(컬렉션)** — 잠긴 카드 클릭 시 유료=뽑기 유도, 프리미엄=스토어로 이동. 잠긴 카드도 블러 처리된 실제 이미지로 미리보기
8. **스토어** — 프리미엄 실물(이 아니라 디지털) 구매 mock
9. **내 계정** — 로그인 상태, 코인, 히든카드 목록, 구매한 프리미엄 목록, 진행 상황 초기화
10. **랭킹** — 오늘 깬 횟수 기준 상위 N% 시뮬레이션, 결과 카드 이미지로 저장(공유용)

히든 왁뿌볼/히든 키캡은 헤더 네비게이션에는 없고, LAB 화면의 "히든 룸" 탭을 통해서만 들어간다(왁뿌볼/키캡 룸에서도 CTA로 바로 갈 수 있음).

- **키캡 스티커 정렬**: 키캡 베이스 사진(1254×1254)에서 실측한 윗면(누르는 면) 사각형 좌표를 `clip-path`로 그대로 적용해서, 사용자가 올린 이미지가 키캡 윗면 기울기에 맞게 잘리고 회전돼서 얹힌다 (`index.css`의 `.keycap-sticker-overlay*`). 원래 8종 기준으로 잡은 좌표라 과일 키캡 10종은 모양이 달라서 약간 어긋날 수 있음
- **키캡 타건 사운드**: 원래 모든 키캡이 쓰던 합성음(저가 키보드 느낌)으로 통일 — `sound.js`의 `playKeyClick(soundFile)`이 파일이 있으면 재생하고 없으면 합성음으로 폴백하는 구조. 팀에서 받은 실제 녹음 5종(`sounds/keyboard-basic-pink.mp3`, `keyboard-basic-white.mp3`, `keyboard-thunder-crystal.mp3`, `keyboard-jewel-bloom.mp3`, `keyboard-hidden.mp3`)을 한때 각 키캡의 `sound` 필드에 매핑했었지만, 녹음 파일이 클릭 한 번 분량으로 잘려있지 않아서(원본 길이 그대로) 한 번만 눌러도 그 길이만큼 계속 소리가 이어지는 문제가 있어 다시 뺐음 — 파일 자체는 `public/sounds/`에 그대로 남아있으니, 팀에서 클릭 한 번 분량으로 트리밍해서 다시 주면 각 키캡 항목에 `"sound": "sounds/파일명.mp3"`만 다시 넣으면 됨
- **왁뿌볼 크런치/파괴 사운드**: `crack-app/src/crunch.js`의 Web Audio 합성 로직을 포팅. 왁뿌볼은 아직 실제 녹음 자체가 팀에 없어서, 프리미엄 등급은 레이어를 한 겹 더 얹은 합성음으로만 차등을 뒀음 — 실제 녹음이 생기면 `sound.js`의 `playCrackHit(progress, isPremium)` 안쪽을 `<audio>` 재생으로 교체
- **뽑기 성공 사운드**만 아직 아무 에셋도 없어서 임시 합성음으로 대체
- 음량 설정은 메인 사이트와 같은 `csl-volume` localStorage 키 공유
- **히든 룸 전용 아트**: 팀에서 받은 어둠 속 보석 콘셉트 이미지 2장을 히든 왁뿌볼(`images/hidden_wakpuball.png`)·히든 키캡(`images/hidden_keycap.png`) 고정 아트로 사용. 일반 룸과 달리 장착한 디자인과 무관하게 항상 이 아트로 고정됨
- **캡슐 뽑기 기계 그래픽**: 받은 캡슐머신 이미지를 사용(`images/gacha_machine.png`) — 기존 핑크 원형 placeholder를 대체. 원본에 체크무늬 배경이 그대로 섞여 있어서(투명 PNG가 아니라 배경이 픽셀로 구워진 상태) R=G=B인 무채색 픽셀만 투명 처리하는 스크립트로 배경을 제거함

- **키캡 실제 녹음 사운드 재적용** — 받은 5종은 클릭 한 번 분량으로 트리밍이 안 돼서 뺐음. 트리밍된 파일을 다시 받으면 `toys.json`의 해당 키캡에 `sound` 필드만 추가하면 바로 적용됨
- **왁뿌볼 금가는 단계별 실제 사진** — 지금은 진행도에 따라 SVG 선이 늘어나는 방식. 팀에서 단계별(살짝 금감/많이 감/깨지기 직전) 사진을 받으면 `src/data/crackStages.js`의 `image` 값만 채우면 자동으로 그 사진이 대신 나오도록 구조만 미리 만들어둠 (`CrackOverlay.jsx`)
- 실제 결제(IAP) 연동, 실제 광고 SDK 연동, 실제 OAuth(카카오/Google) 연동 — 전부 화면과 흐름만 만든 mock
- 데일리 보너스, 한정판 기간제
- 비주얼 톤 A(기밀문서 케이스파일)를 기본으로 잡음

## 데이터 구조

`src/data/toys.json`만 수정하면 종류가 늘어납니다(코드 수정 불필요) — `tier`를 `free`/`paid`/`premium` 중 하나로, `premium`이면 `price`(원)까지 넣어주면 됩니다.
