# POPPIN ROOM (csl-gacha-v2) — 왁뿌볼 · 키캡 피젯 랩

## POPPIN ROOM 전환 (2026.09.17)

브랜드명이 **포핀룸 POPPIN ROOM**으로 정해져서, 저장소에는 이 앱(`csl-gacha-v2/`)만 남기고 예전 CSL LAB 정적 사이트는 전부 지웠습니다. 민지님이 올린 랜딩 초안(`poppin-room-landing-page/`)은 별도 폴더 대신 앱의 첫 화면으로 그대로 옮겼습니다.

- **첫 화면 = 랜딩** (`src/pages/Landing.jsx`, `src/landing.css`): 초안의 마크업·문구·스타일을 그대로 두고(`.landing` 아래로 스코프만 씌움) 링크만 실제 화면으로 연결. 시작하기 → 왁뿌볼 룸, 컬렉션 보기 → 컬렉션, 상점 보기 → 상점 & 랭킹, PLAY MODES 카드 6개도 각 화면으로 이동. 하단 숫자 3칸(팝볼/오브제/시크릿)은 실제 진행 상태(누적 깬 횟수 / 보유 오브제 수 / 히든카드 수)
- **로고 문구만** `POPPIN ROOM`으로 교체 — 왁뿌볼/키캡 같은 제품 용어는 그대로
- **상점 & 랭킹** (`Shop.jsx`): 예전 스토어 + 랭킹 화면을 한 페이지로 합침. `/store`, `/ranking` 주소는 `/shop`으로 리다이렉트
- **키캡 룸**: 8칸 고정 KEY-DECK 대신 **보유한 디자인마다 키 1개씩** 나열(누르면 장착 + 고유 사운드)
- **컬렉션 = 가방 + 내 방** (`Collection.jsx`, `components/RoomStage.jsx`): 위쪽 "내 방"에 가방(보유 오브제)의 오브제를 놓고 **드래그로 원하는 위치에 자유 배치**(마우스·터치, 최대 6개). 가방에서 카드 선택 → 장착하기 / 방에 놓기, 방의 오브제는 × 버튼으로 가방 회수. 위치는 방 기준 % 좌표로 `useGame`의 `room`에 저장(localStorage)
- **시크릿 룸** (`Secret.jsx`): 랜딩의 "조건을 달성하면 열리는 방" 입구. **진입 조건은 미정(팀 논의 예정)**이라 지금은 기존 히든 왁뿌볼/키캡 룸으로 바로 들어가짐
- **뽑기**: 그대로
- 예전 LAB 홈(`Lab.jsx`)은 랜딩이 대신하므로 삭제, `/lab`은 `/`로 리다이렉트
- 배포: 루트 GitHub Actions가 이 폴더를 `vite build` 해서 `dist/`를 Pages에 올림 (`vite.config.js`에 `base: './'`)

박준성님 `CSL v2 재기획안`(2026.09.14)에 적힌 프롬프트 순서를 뼈대로, 이후 피드백(흰 배경, 단일 키캡, 무료/유료/프리미엄 코인 경제, 히든카드)까지 반영한 버전입니다.

## V2 UI 리디자인 (`CSL_Prototype.pdf` 참고)

팀에서 받은 `CSL_Prototype.pdf`(5화면: LAB 홈 / 왁뿌볼 상세 / 키캡 KEY-DECK / OBJECT DRAW / OBJECT ARCHIVE)를 참고해서 홈·왁뿌볼·키캡·뽑기·도감 5개 화면을 흰 카드 + 검정 필 버튼 + 컬러 배지 스타일로 다시 그렸습니다. 새 컴포넌트 클래스는 전부 `v2-` 접두사(`index.css` 맨 아래 "V2 UI" 섹션)로 모아뒀고, 기존 케이스파일(모노폰트/라임 컬러) 톤의 스토어·랭킹·내 계정 화면은 이번엔 손대지 않았습니다.

- **LAB 홈**: 코인을 "오늘 누적된 스트레스 게이지" 카드(진행률 = 보유 코인/500)로 보여주고, 룸 목록을 "ACTIVE PLAYROOMS" 리스트(원형 썸네일 + 장착중 배지 + 화살표)로, 뽑기 CTA를 검정 "STRESS RELIEVING DRAW" 패널로 바꿈
- **왁뿌볼 상세**: "NO. 0X {이름} / STRESS: {LOW·MEDIUM·HIGH}" 헤더(등급 기반), 칠 때마다 "💥 콤보 x{n} 연타중!" 배지가 뜨고, 균열도 %가 진행바로 표시됨(`WakpuStage.jsx`). 하단 버튼 2개 — "오브제 변경"(기존 `DesignPicker` 재사용, 라벨만 교체)과 "게이지 수확하기"(랭킹 페이지로 이동)
- **키캡 룸 — KEY-DECK로 전면 개편**: 기존 "장착된 키 하나만 누르는" 방식을 버리고, **보유한 키캡 디자인을 최대 8개까지 A/S/D/F/J/K/L/; 자리에 동시에 배치**해서 아무 키나 눌러 그 디자인 고유 사운드로 타건할 수 있게 함. 누른 키가 곧 장착 키가 됨(`equip` 호출). ASMR 토글은 이 페이지 안에서만 사운드를 껐다 켜는 로컬 스위치(사이트 전역 음량과는 별개). "오늘의 타건 게이지 적립"은 새로 추가한 `dailyKeyCoins` 상태(자정에 리셋)로 실제 집계됨 — 8칸보다 보유 디자인이 적으면 남는 칸은 빈 채로 비활성 표시됨
- **뽑기(OBJECT DRAW)**: 결과 카드를 점선 원 + 등급 배지 스타일로, "DRAW RATES" 박스도 추가함 — 단, 실제 뽑기 로직은 유료 등급 안에서 균등 확률 1개 뽑기라서(등급별 가중치가 없음) mockup의 Common 70%/Rare 25%/Limited 5% 같은 **가짜 확률표는 넣지 않고**, "유료 등급 오브제 N종 중 균등 확률 1/N"로 사실대로 표시함
- **도감(OBJECT ARCHIVE)**: 섹션 나열 대신 "왁뿌볼 (n) / 키캡 (n)" 탭 전환 + 3열 그리드(배지: 장착중=ACTIVE, 보유=등급, 잠김=LOCKED 자물쇠)로 바꾸고, 카드를 누르면 즉시 장착되던 것에서 **먼저 상세 패널이 뜨고 거기서 "이 오브제로 장착하기"를 눌러야 장착**되는 2단계 흐름으로 바꿈

### 반영 안 한 부분 (의도적 단순화)
- 코인 단위를 mockup의 "SP"로 바꾸지 않고 기존 "코인" 그대로 유지 — 이름만 바꾸는 문제가 아니라 스토어/등급 구조/README 전반에 걸친 용어라 이번 스코프에서는 시각적 리디자인에 집중함
- 페이지 제목을 mockup처럼 영문("OBJECT DRAW" 등)으로 바꾸지 않고 기존처럼 한글 제목 유지 — 다른 화면(스토어/랭킹/내 계정)이 전부 한글 제목이라 일관성을 위해 그대로 둠
- KEY-DECK에 넣을 새 키캡 사진(마시멜로/버터빵 등 mockup 속 디자인)은 아직 안 왔음 — 지금은 기존 보유 키캡 디자인으로 그리드를 채워둠. 사진 오면 `toys.json`에 추가만 하면 그리드에 자동으로 들어감

## 왁뿌볼 깨지는 손맛 — 크런치 → 리셋

CRACK LAB(`crack-app`, 참고용으로 팀에서 공유한 wakbuball-game.pages.dev)의 "금이 가며 깨지는" 인터랙션 느낌을 우리 방식대로 다시 구현했습니다. 디자인을 그대로 베낀 게 아니라 **기능만 참고**했습니다.

- 누를 때마다 최소 260ms 간격을 두고서만 타격이 등록됨(`HIT_COOLDOWN_MS`) — 그 안에 더 눌러도 무시돼서 "탁탁탁탁" 연타가 아니라 "탁···탁···탁" 한 번씩 묵직하게 박히는 느낌을 줌
- 다 깨지기 전부터 진행도에 비례해서 금 간 틈으로 흰 왁스가 조금씩 비침(`CrackOverlay.jsx`의 `wakpu-wax-glow`/`wakpu-wax-drop`) — 예를 들어 15번 쳐야 깨지는 왁뿌볼이면 초반 몇 번만 쳐도 벌써 살짝 하얗게 비치기 시작해서, 다 깨질 때 갑자기 왁스가 나타나는 게 아니라 자연스럽게 이어짐
- 칠 때마다 진행도에 비례해서 점점 더 세게 짓눌렸다 튕기는 반응 (`WakpuStage.jsx`, `--hit-squash` CSS 변수)
- 다 깨지면 겉껍질이 디자인별 `accent` 색 파편으로 튀는 연출(`wakpu-shatter`)이 잠깐 나온 뒤, 바로 새 왁뿌볼(진행도 0)로 리셋됨 — 다 깨진 뒤 "말랑말랑 눌러보는" 별도 단계는 없앰
- 왁뿌볼 룸·히든 왁뿌볼 룸이 이 로직을 공유(`WakpuStage.jsx`)
- 키캡 룸·히든 키캡 룸은 이 쿨다운을 공유하지 않음(별도의 `Keycap.jsx`/`HiddenKeycap.jsx` 클릭 핸들러, `.keycap-single`의 0.06s 트랜지션) — 실제로 만졌을 때 왁뿌볼과 키캡은 속도감이 다르기 때문에, 키캡은 누르는 대로 빠르게 "탁탁탁탁" 눌렸다 올라오며 반응함

## 등급 구조 — 무료 / 유료 / 프리미엄

디자인 등급(common/rare/limited 배지)과 별개로, **획득 방식**을 결정하는 `tier` 필드가 있습니다.

| tier | 배지 | 획득 방법 |
|---|---|---|
| `free` | COMMON | 처음부터 자동 보유 (왁뿌볼·키캡 각 3종) |
| `paid` | RARE | 뽑기 전용 — 코인 10개 소비, 유료 등급 중 랜덤 1개 (각 3종) |
| `premium` | LIMITED | 스토어에서 실제 결제로 구매 (각 2종, ₩2,900~3,900) |

## 코인 경제

- 왁뿌볼을 칠 때마다, 키캡을 누를 때마다 랜덤 보상 굴림: **35% 1코인 · 5% 5코인**. 일반 룸에서는 코인만 나오고 히든카드는 안 나옴(히든카드는 히든 룸 전용, 아래 참고)
- 뽑기 1회 = 코인 10개. 이미 보유 중인 디자인이 나오면 코인 30% 환급
- 광고 보고 5코인 받기 — 실제 광고 SDK가 없어서 지금은 "광고 재생 중..." 흉내만 내고 5코인을 바로 지급하는 mock (`Gacha.jsx`의 `handleWatchAd`, `useGame.jsx`의 `claimAdCoins`)

## 히든카드 & 히든 룸

- 일반 왁뿌볼/키캡 룸과는 완전히 분리된 전용 룸(**히든 왁뿌볼**, **히든 키캡**)이 있음 — 여기서는 코인이 전혀 안 나오고, 누를 때마다 **0.6% 확률로 히든카드만** 노려볼 수 있음. 두 룸 모두 룸 고유의(장착한 디자인과 무관한) 어둠 속 보석 아트로 고정돼 있음
- 하루 시도 횟수 제한: 기본 **40번**, 다 쓰면 **광고 1편(30초) 시청당 20번씩 최대 60번**까지 늘릴 수 있음 (`HiddenGauge.jsx`)
- 60번(또는 광고 없이 40번)을 전부 쓰면, **그 주기가 시작된 시점으로부터 24시간**이 지나야 40번으로 다시 풀림 — 달력 날짜가 아니라 실제 24시간 롤링 윈도우 (`useGame.jsx`의 `pressHidden`/`isHiddenMaxed`, `HIDDEN_CYCLE_MS`)
- 히든카드를 획득하면 화면 전체 축하 모달 표시 → 「내 계정」 탭에 코드·획득일과 함께 계속 보관됨
- 실물 상품 수령에는 실제 계정 시스템이 필요하다는 안내만 표시(아직 미구현)

## 로그인 (mock)

- 헤더 우측 "로그인" → 카카오/Google 버튼 중 하나 누르면 바로 로그인 처리되는 스텁 (`useGame.jsx`의 `login`/`logout`)
- 실제 OAuth 연동 전까지는 이 mock으로 "로그인 → 내 계정 탭" 흐름만 보여줌
- 로그인 전엔 히든카드·프리미엄 보유 내역이 안 보이고 로그인 유도 화면만 나옴

## 화면 구성 (10개) — POPPIN ROOM 전환 전 기준, 위 섹션의 변경 사항이 우선

1. **LAB** — 코인 잔액, 뽑기 CTA, "일반 룸 / 히든 룸" 탭으로 전환되는 룸 입구 4개(아래 2~5번)
2. **왁뿌볼 룸** *(일반 탭)* — 단일 볼, 연타 → 깨짐 → 코인 굴림, 보유 디자인 즉시 장착(디자인 선택 UI), 오늘 깬 횟수 → 랭킹 링크, 히든 왁뿌볼 룸 CTA
3. **히든 왁뿌볼 룸** *(히든 탭)* — 룸 전용 고정 아트(반짝이는 홀로그램 연출), 코인 없이 0.6% 히든카드만. 하루 40번(광고로 최대 60번), 24시간 롤링 리셋
4. **키캡 룸** *(일반 탭)* — KEY-DECK: 보유한 키캡 디자인을 최대 8개까지 A/S/D/F/J/K/L/; 자리에 동시 배치, 아무 키나 누르면 그 디자인 사운드로 타건 + 자동으로 그 디자인이 장착됨(90ms 눌림 애니메이션, ESC 키는 현재 장착 키로 동작), ASMR 사운드 로컬 토글, 오늘의 타건 게이지 적립 표시, 히든 키캡 룸 CTA
5. **히든 키캡 룸** *(히든 탭)* — 룸 전용 고정 아트(반짝이는 홀로그램 연출), 코인 없이 0.6% 히든카드만. 하루 40번(광고로 최대 60번), 24시간 롤링 리셋
6. **뽑기** — 코인 소비, 유료 등급만 등장, 결과 화면에서 바로 장착 가능, 실제 캡슐머신 그래픽
7. **도감(컬렉션)** — 왁뿌볼/키캡 탭 전환, 카드 클릭 시 상세 패널이 뜨고 거기서 장착(보유 중)·구매하러 가기(프리미엄)·뽑기로 가기(유료) 버튼 표시
8. **스토어** — 프리미엄 실물(이 아니라 디지털) 구매 mock
9. **내 계정** — 로그인 상태, 코인, 히든카드 목록, 구매한 프리미엄 목록, 진행 상황 초기화
10. **랭킹** — 오늘 깬 횟수 기준 상위 N% 시뮬레이션, 결과 카드 이미지로 저장(공유용)

히든 왁뿌볼/히든 키캡은 헤더 네비게이션에는 없고, LAB 화면의 "히든 룸" 탭을 통해서만 들어간다(왁뿌볼/키캡 룸에서도 CTA로 바로 갈 수 있음).
