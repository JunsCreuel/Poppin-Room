# 텍스트 스타일 규칙

이 프로젝트의 모든 UI 카피(설명 문구, 버튼, 토스트, 빈 상태 문구, 확인창 등)는
**무조건 간결체**로 작성한다. 문장형 어미 대신 명사/구 단위로 끝낸다.

- 금지: "~해봐", "~있어", "~돼", "~해야 해", "~노려볼 수 있어" 같은 서술형·청유형 문장 어미
- 예시: "구글에서 로그인", "상점에서 구매 획득 가능", "연타로 파괴, 칠 때마다 코인 획득 가능"
- 쉼표로 절을 나열하는 식으로 짧게 끊고, 마침표 없이 끝내는 걸 기본으로 한다.

새 화면/문구를 추가하거나 기존 문구를 수정할 때마다 이 규칙을 적용한다.
