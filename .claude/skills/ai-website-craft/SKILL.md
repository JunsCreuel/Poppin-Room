# AI 티 줄이는 웹사이트 제작법

Studio Nutty의 AI 웹사이트 제작 가이드를 기반으로 한 요청·제작 순서. 목표는 "AI가 뚝딱 만든 것 같은" 느낌을 줄이고, 의도가 분명한 사이트를 만드는 것.

## 1. 방향부터 정하기 — 의도 / 규칙 / 수치로 분리

막연하게 "예쁘게 해줘" 대신, 아래 세 가지를 구분해서 받는다. 숫자(각도·시간·px 등)는 사용자가 안 주면 이쪽에서 화면에 맞게 정하고, 조절 가능한 부분이 뭔지 알려준다.

- **의도**: 어떤 느낌이어야 하는지 (예: "귀여운 캐릭터가 커서를 따라 고개를 돌리면 좋겠어, 분위기는 따뜻하고 장난스럽게")
- **규칙**: 뭘 움직이고 뭘 고정할지 (예: "몸통은 그대로 두고 고개만 움직여. 커서가 화면을 벗어나면 정면을 보게 해. 다른 요소는 안 건드려.")
- **수치**: 각도·속도·강도 등 — 사용자가 안 주면 Claude가 정하고 조절 포인트를 함께 안내

## 2. 한 줄 컨셉으로 정리

작업 들어가기 전에 아래 틀로 한 줄 요약해서 사용자에게 확인받는다.

> [누구]를 위한 [어떤 사이트]. 핵심 경험은 [인터랙션]. 분위기는 [단어 3개].

예: "브랜드 의뢰인을 위한 디자인 스튜디오 소개 사이트. 핵심 경험은 커서를 따라 고개를 돌리는 캐릭터. 분위기는 알싸함, 따뜻함, 장난스러움."

## 3. 레퍼런스는 포인트까지 뜯어서 받기

"이 사이트처럼 해줘"로 끝내지 말고, 뭐가 좋은지 구체적으로 짚는다.

- "깔끔하다" → 3단으로 나뉜 화면, 넓은 여백, 박스 없는 구성 같은 식으로 분해
- "글씨가 예쁘다" → 제목은 크고 굵게, 본문은 얇고 가볍게 같은 식으로 분해

사용자가 "그냥 저 느낌으로"라고만 하면, 이쪽에서 레퍼런스를 보고 이렇게 구체적인 포인트로 나눠 먼저 제시하고 확인받는다.

## 4. 요청받기 전에 채워야 할 7항목

"예쁘게"보다 먼저 아래를 채운다. 사용자가 다 안 줘도, Claude가 명시적으로 하나씩 정하거나 물어보고 진행한다.

1. **만들 사이트** — 무엇을 만들고, 무엇을 뺄지
2. **분위기** — 처음 들어왔을 때 어떤 느낌이면 좋을지
3. **색과 글씨** — 색상 3~5개, 폰트 2개
4. **화면 배치** — 데스크톱/모바일에서 각각 어떻게 보일지
5. **이미지·영상** — 무엇을 쓸지, 새로 만들어야 할지
6. **움직임과 반응** — 언제 움직이고 멈추는지, 하면 안 되는 동작
7. **사용하기 편하게** — 터치 동작, 움직임 줄인 버전(모션 감소 설정) 챙기기

## 5. 한 번에 다 만들지 않기 — 순서대로 쌓기

화면부터 잡고, 움직임은 나중에. 하나씩 확인하며 진행한다.

1. 이미지·영상부터 준비 (필요하면 먼저 생성·수급)
2. 움직임 없이 화면 배치부터 완성
3. 배치가 마음에 들면 그 위에 움직임만 추가
4. 모바일에서 터치 동작·움직임 줄이기 설정까지 반영

### 수정은 한 가지씩

- 복잡하다는 피드백 → 장식용 요소를 최소한으로 정리
- 움직임이 과하다는 피드백 → 가장 중요한 동작 하나만 남기고 나머지 제거
- 속도만 바꾸고 싶다는 피드백 → 배치와 색은 그대로 두고 속도값만 조정

### 마지막 체크리스트

스크롤 · 커서 반응 · 모바일 터치 · 버튼과 링크 동작까지 확인하고 마무리한다.

## 6. 바로 쓸 수 있는 효과 2종

색·글꼴 크기까지 못박은 프롬프트. 사용자가 "트위스트 스플릿"이나 "심리스 머지" 효과를 요청하면 아래 스펙 그대로 구현하고, 색/크기/문구는 실제 프로젝트에 맞게 치환한다.

### Twist & Split — 글자가 비틀리며 전환되는 효과

- **구조**: 문구를 한 글자씩 나누고, 같은 글자를 두 겹으로 만든다. 각 글자 칸 높이는 1.15em, `overflow:hidden`. 전체에 `perspective:600px`, 각 글자에 `perspective:200px` 적용. 문구의 원래 접근성(스크린리더 등)은 유지한다.
- **동작**: 호버하면 글자마다 22ms 시차를 두고 0.65초 동안 `cubic-bezier(.16,1,.3,1)`로 전환. 위쪽 글자는 `translateY(-100%) rotateX(80deg) rotateZ(-12deg) opacity:0`으로, 아래쪽 글자는 `translateY(100%) rotateX(-80deg) rotateZ(12deg) opacity:0`에서 정면(`opacity:1`)으로 바뀐다. 회전 기준점은 `50% 50% -0.3em`.
- **조건**: 호버가 끝나면 원상 복귀하고 글자 자리·조작 영역은 고정. 키보드 포커스·모바일 탭도 지원. 모션 감소 설정에서는 회전 없이 색상만 바뀌게 처리. 기존 사이트에 적용할 땐 주변 구조를 유지하고, 전체 코드와 적용 방법을 함께 안내한다.

### Seamless Merge — 두 조각이 하나의 카드로 합쳐지는 효과

- **구조**: 세로 flex 중앙 정렬. 카드 전체는 `330x200px`, 가로 flex, `gap:8px`. 본체는 `ff4d00` 배경에 `257px` 너비·`25px` 패딩, 스텁(티켓 반쪽)은 `65px` 너비에 `eee` 배경. 두 조각 모두 모서리 반경 `18px`, 글자색 `#111`.
- **배치**: 본체는 세로 flex-start 정렬. 위에 작은 라벨(예: monospace 11px, 자간 .12em), 아래 메인 텍스트를 두 줄로 배치. 스텁 중앙에는 세로쓰기(`writing-mode: vertical-rl`) 텍스트를 monospace 12px·자간 .12em으로 넣는다.
- **동작**: 호버하면 스텁을 왼쪽으로 8px 이동하고, 맞닿는 모서리 반경을 0으로 바꿔 한 장으로 연결된 느낌을 준다. 제목은 위로 32px 이동, 본문 아래쪽 텍스트는 15px 아래에서 `opacity:0`으로 나타낸다. 스텁 라벨은 오렌지색으로 바뀐다. 이동은 `.65초`, 색 전환은 `.5초`, 이징은 `cubic-bezier(.16,1,.3,1)`.
- **조건**: 호버 종료 시 자리·문구 모두 복귀. 카드 전체 조작 영역은 고정, 클릭/탭으로 상태를 전환하게 만들고 `aria-pressed` 지원. 모바일에서는 호버 대신 탭으로 상태를 유지하고, 모션 감소 설정에서는 이동 없이 색상 전환만 남긴다.
